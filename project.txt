بصفتك فريق تطوير هندسي متكامل ومحترف لأنظمة سطح المكتب، أريد منك تصميم وبناء برنامج تحميل سطح مكتب متطور وخارق للسرعة ينافس برامج مثل IDM، ومسمى رسمياً "Ledo Downloader".

التقنيات المستخدمة في المشروع:
- واجهة المستخدم (Frontend): HTML, CSS, JavaScript (تصميم عصري، مظهر مظلم Dark Mode، واجهة تفاعلية وسلسة).
- إطار العمل المكتبي (Desktop Wrapper): Electron (لدمج الواجهة مع الباك إند بأمان تام).
- نواة التحميل (Backend Core): Python (يعتمد على مكتبة 'yt-dlp' للميديا، ونظام تحميل متوازي ومجزأ Multi-threaded Chunks للملفات العادية لشفط أقصى سرعة ممكنة من خط الإنترنت وتجاوز اختناقات المتصفح).
- نظام الربط (Integration): خادم محلي خفيف Local API Server (باستخدام FastAPI) لربط البرنامج بإضافة متصفح مخصصة تلتقط الروابط فوراً.

المميزات الأساسية والخارقة المطلوب برمجتها وتصميمها في التطبيق:
1. نظام الشفط الفائق للسرعة (Multi-Connection Chunking): تقطيع الملف الواحد إلى أجزاء متعددة وتنزيلها بالتوازي لاستغلال كامل سرعة خط الإنترنت، لحل مشكلة سقوط السرعة في المتصفح.
2. دعم شامل لكل أنواع الملفات والميديا: تحميل الفيديوهات من يوتيوب وكل المنصات عبر yt-dlp، وتحميل الملفات المباشرة (تطبيقات، ملفات مضغوطة، مستندات) بأقصى سرعة.
3. متصفح مصغر داخلي (In-App Browser): نافذة متصفح مدمجة داخل التطبيق لتصفح المواقع وسحب أو تحميل أي محتوى بضغطة زر مباشرة.
4. نظام إدارة التحميلات المتقدم: إيقاف مؤقت (Pause)، استئناف (Resume)، جدولة التحميلات، وتنظيم الملفات في مجلدات مخصصة تلقائياً حسب نوعها.
5. نظام الحماية ضد الحظر (Anti-False Positive Setup): كتابة كود نظيف وتوفير إعدادات التغليف عبر PyInstaller و Electron-Builder بطريقة تقلل تماماً من إنذارات برامج الحماية (Windows Defender).

المطلوب منك الآن:
- تصميم هيكل المجلدات الأساسي للمشروع كاملاً.
- كتابة كود البايثون الخاص بنواة التحميل (تجزئة الملفات + yt-dlp).
- كتابة كود Electron الرئيسي (main.js) لربط الواجهة بالباك إند عبر الخادم المحلي.
