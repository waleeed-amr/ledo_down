# **Ledo Downloader v3.9.2018**

---

### 🌟 **الميزات الجديدة والتحسينات (بالعربية)**

* **⚡ محرك تحميل فائق السرعة:** الاعتماد على نظام **Multi-Connection Chunking** لتقطيع الملفات وتنزيلها عبر خيوط متوازية لاستغلال أقصى سرعة لخط الإنترنت.
* **🎬 دعم شامل ومطوّر للميديا:** تحديث محرك `yt-dlp` و `ffmpeg` لتحميل الفيديوهات بأعلى جودة وتفكيك الصوتيات بسهولة من أكثر من 1800 موقع.
* **📋 مراقب الحافظة الذكي (Smart Clipboard):** التقاط الروابط المدعومة من الحافظة تلقائياً واقتراح تحميلها بنقرة واحدة.
* **🌐 تكامل عميق مع المتصفح:** دعم الاتصال المباشر مع إضافة المتصفح التقاط الروابط والفيديوهات المخفية فوراً.
* **🎨 واجهة مستخدم متطورة (RTL):** دعم كامل للغة العربية بتصميم عصري (Dark Mode & Glassmorphism) وأداء خفيف وسلس.
* **🔄 تحديثات جزئية سريعة:** تفعيل تقنية الـ **Differential Updates** لتنزيل التحديثات القادمة بحجم صغير جداً في الخلفية.

### 🌟 **New Features & Enhancements (English)**

* **⚡ Supercharged Download Engine:** Powered by **Multi-Connection Chunking** to split files into parallel streams for maximum speed.
* **🎬 Advanced Media Support:** Upgraded `yt-dlp` & `ffmpeg` cores to support downloading high-quality videos and audio extraction from 1800+ sites.
* **📋 Smart Clipboard Monitor:** Automatically detects copied media links and offers instant one-click downloads.
* **🌐 Browser Extension Integration:** Seamless connection with Chrome/Edge extensions to capture embedded video links instantly.
* **🎨 Modern User Interface:** Full **RTL** Arabic language support with sleek Dark Mode and fluid Glassmorphism visuals.
* **🔄 Fast Differential Updates:** Enabled lightweight background updates so future releases require minimal data download.
